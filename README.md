# 00-tools

ChatGPTにツールを作らせて、必要なものだけダウンロードするための保管庫です。

## ChatGPT複数表示

ダウンロードするのは `ChatGPT複数表示.cmd` の1ファイルだけです。

初回起動時に、同時表示したいChatGPTチャット数（2～4）と各チャットURLを入力します。
その設定はPC側に自動保存されます。2回目以降の起動時は、保存済みチャットをそのまま開くか、チャットを入れ替えるかを選べます。引き継ぎなどでチャットが変わった場合も、同じ1ファイルから設定を更新できます。

通常はGoogle Chromeを使い、見つからない場合はMicrosoft Edgeを使います。


## Windows用CMDを作るときの共通ルール

今後このリポジトリでWindows用の `.cmd` / `.bat` を作る場合は、次を必須にします。

- 失敗してもウィンドウを自動で閉じない
- エラー内容を画面に表示する
- エラー内容をログにも保存する
- PowerShellなど別機能を呼ぶ場合は、存在確認をしてから実行する
- 一時ファイルを使う場合は、成功時だけ自動削除する
- 可能な限りダウンロードするファイルは1個にまとめる
- 初回起動時の設定はPC側に自動保存し、再設定もできるようにする
- 作成後は、古い処理や重複コードが混ざっていないか確認する

特に「一瞬で閉じて原因が分からない」状態は禁止です。
