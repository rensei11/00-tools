# 00-tools

ChatGPTにツールを作らせて、必要なものだけダウンロードするための保管庫です。

## ChatGPT複数表示

ダウンロードするのは `ChatGPT複数表示.cmd` の1ファイルだけです。

初回起動時に、同時表示したいChatGPTチャット数（2～4）と各チャットURLを入力します。
その設定はPC側に自動保存され、2回目以降は `ChatGPT複数表示.cmd` をダブルクリックするだけで、保存した2～4個のChatGPTチャットを縦長で横並びに開きます。

通常はGoogle Chromeを使い、見つからない場合はMicrosoft Edgeを使います。
