# 00-tools

ChatGPTに小さなツールを作らせて、必要なものだけダウンロードするための保管庫です。

## ChatGPT複数表示

現在は **`ChatGPT複数表示.html` の1ファイルだけ**を使います。

- PowerShellを使いません
- コマンドプロンプトを使いません
- 裏で待機する処理を使いません
- 2～4個のChatGPTチャットURLを保存できます
- 引き継ぎなどでURLが変わったら、画面上で書き換えられます
- 「保存して開く」を押すと、縦長の別ウィンドウとして横並びに開きます

ブラウザが複数ウィンドウを止めた場合は、そのファイルに対してポップアップを許可してから、もう一度「保存して開く」を押します。

## Windows用ツールの作成ルール

- ブラウザだけで実現できるものは、CMD/PowerShellよりHTMLを優先する
- CMD/BATを使う必要がある場合は、失敗時に自動で閉じない
- エラー内容を画面とログに残す
- 作成後に全文を再確認する
- 古い処理や重複コードが残っていないか確認する
- ダウンロード対象はできるだけ1ファイルにまとめる

## Fandom音声ツール自動更新

`fandom-voice-tool-latest.json` はFandom音声ツールの自動更新用ファイルです。通常はユーザーが直接操作する必要はありません。
